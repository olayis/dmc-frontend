# Dev Mentorship Community — Frontend

Teaching code and exercises for the DMC frontend mentorship, led by [Olusegun Olayinka](https://github.com/olayis). Live classes run Saturdays on Google Meet.

## What's here

| Folder | Track |
|---|---|
| [`frontend-ai/`](frontend-ai/) | **Frontend + AI series (current)** — an 8-session series where every mentee builds and deploys their own AI app. Starts with a streaming AI feature in React behind a proxy server. |
| [`junior-track/`](junior-track/) | Earlier junior-track sessions: closures, async JavaScript |
| [`intermediate-track/`](intermediate-track/) | Earlier intermediate-track sessions: async JavaScript with real APIs |

## The Frontend + AI series (8 sessions)

1. Build your first AI feature into a React app (streaming, loading and error states, proxy server)
2. State management done right
3. Testing frontend properly
4. Prompt engineering and structured output
5. RAG: chat with your own documents
6. Agents and tool use
7. Evaluating AI features so they don't hallucinate
8. Ship to production, plus demo day
